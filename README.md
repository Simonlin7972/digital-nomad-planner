# 2027 數位遊牧計畫

一頁式的年度行程規劃工具：把一整年拆成 53 週，拖一拖就排好「幾月在哪個城市」。資料只存在你的瀏覽器，沒有帳號、沒有後端。

**線上版：<https://simonlin7972.github.io/digital-nomad-planner/>**

![整年時間軸與行程清單（範例資料）](docs/overview.png)

> A single-page planner for a year of digital nomading. Drag across a 53-week timeline to block out where you'll be, refine exact dates in a month view, and see the route on a map. Everything stays in your browser — no account, no backend. The interface is in Traditional Chinese.

## 功能

### 年檢視（時間軸）

- 單條橫向時間軸，2027 全年 53 週，每週一格，格內再分半週
- 在空格上拖選 → 填國家與城市 → 產生一段行程色塊
- 整塊拖曳是**換順序**：拖過鄰居的一半就跟它對調，可一路換下去
- 拉色塊兩端是**伸縮並推擠**：變長時把鄰居往同方向推，空檔先被吃掉
- 按住 `Alt`（Mac 為 `⌥`）拖色塊是**複製**：原本的不動，在放開的位置多一段同樣的行程，擋路的會被推開
- 色塊下方有國家條（國旗＋國名），相鄰且同國家的行程合併成一條
- 縮放 100%–600%：滑桿、觸控板 pinch、兩指觸控、`Ctrl`／`Alt` + 滾輪，皆以游標為中心
- 按住月份列可左右拖曳平移；點月份標題跳到該月的月檢視

### 月檢視（月曆）

- 7 欄月曆格，以**天**為單位
- 在日期上拖選新增行程；拉橫條兩端調整起訖日；點橫條編輯
- 標題列顯示當月已安排／未安排天數

### 每段行程可記錄

- 國家、城市（至少填一項）。國家從可搜尋的選單挑選：繁體中文名稱，可用中文、英文、國碼或常見別名搜尋（例如打 `thai`、`jp`、`韓國`）
- 確切開始日、結束日
- 顏色（8 色）
- 跟誰去
- 已買機票：航空公司、航班編號、起飛時間、訂位代號、票價
- 備註

### 總覽

- **摘要**：已安排／未安排週數、去了幾個國家與城市、估計航段數與飛行時數、依國家分組的停留週數與天數
- **行程列表**：一段行程一列——日期、國旗與國家、城市、週數（天數）、跟誰去、備註；可依 Q1–Q4 篩選；有機票的行程顯示票券圖示
- **地圖**：依時間順序標出每個地點並連成路線
- **國定假日**：可開關台灣、澳洲 2027 年國定假日，疊在時間軸與月曆上

### 其他

- 復原／重做，最多 100 步
- JSON 匯出／匯入
- 保存 PNG：整年時間軸加行程清單，固定尺寸
- 所有變更自動儲存

## 快速開始

需要 Node.js 22 以上。

```bash
git clone https://github.com/Simonlin7972/digital-nomad-planner.git
cd digital-nomad-planner
npm install
npm run dev
```

開啟 http://localhost:5173 。

| 指令 | 用途 |
| --- | --- |
| `npm run dev` | 啟動開發伺服器（固定 5173 埠） |
| `npm run build` | 型別檢查後打包到 `dist/` |
| `npm run preview` | 在本機預覽打包結果 |

打包結果是純靜態檔案，可放在任何靜態主機。資源路徑是相對的（`vite.config.ts` 的 `base: './'`），所以放在子路徑下也能運作。

### 部署

推到 `main` 會由 GitHub Actions（`.github/workflows/deploy.yml`）自動打包並發佈到 GitHub Pages。Fork 之後要自己部署：到 repo 的 Settings → Pages，把 Source 設為 **GitHub Actions**。

線上版和本機版各用各的瀏覽器儲存空間（網址不同），資料不互通；要搬移請用匯出／匯入。
目前沒有自動化測試，也沒有 lint 設定；`npm run build` 內含的 `tsc --noEmit` 是唯一的檢查。

## 資料與隱私

**你的行程不會上傳到任何伺服器。** 所有資料存在瀏覽器的 `localStorage`：

| Key | 內容 |
| --- | --- |
| `dnp-plan-2027` | 行程本體 |
| `dnp-geocode` | 地名查到的座標快取 |
| `dnp-zoom` | 時間軸縮放比例 |
| `dnp-view` | 目前檢視（年／月）與月份 |
| `dnp-holidays` | 假日開關狀態 |

清除瀏覽器資料、換瀏覽器或換電腦都會看不到行程，請用「匯出」備份。

頁面會對外連線到下列三個服務：

| 服務 | 送出的內容 | 用途 |
| --- | --- | --- |
| [Nominatim](https://nominatim.openstreetmap.org/)（OpenStreetMap） | 你輸入的「城市, 國家」文字 | 查座標，供地圖與飛行估算使用。每個地名只查一次 |
| [OpenFreeMap](https://openfreemap.org/) | 地圖圖磚請求 | 地圖底圖 |
| [emfont](https://font.emtech.cc/) | 字型檔請求 | 介面字體 |

機票的訂位代號等欄位會存在 `localStorage`，也會寫進匯出的 JSON。分享匯出檔之前請留意。

## 資料格式

匯出的 JSON：

```jsonc
{
  "year": 2027,
  "stays": [
    {
      "id": "0b7c…",              // 省略時匯入會自動產生
      "country": "泰國",           // 可為空字串，但不可與 city 同時為空
      "city": "清邁",
      "start": "2027-02-10",      // ISO 日期
      "end": "2027-03-07",        // 含當日，需 >= start
      "color": "teal",            // 選填：red orange yellow green teal blue purple pink
      "companions": "Amy",        // 選填
      "ticket": {                 // 選填；物件存在即代表「已買機票」，欄位皆選填
        "airline": "長榮航空",
        "flightNo": "BR211",
        "departure": "2027-02-10T08:30",
        "bookingRef": "ABC123",
        "price": "NT$ 8,500"
      },
      "note": "水燈節"             // 選填
    }
  ]
}
```

匯入時會做清理（`sanitize`）：格式不對、日期超出範圍、或與前面行程重疊的項目會被略過，不會讓整份檔案失敗。

可用日期範圍是 2026-12-28 到 2028-01-02，也就是涵蓋 2027 年的完整 53 週。

向下相容兩種舊格式：以週為單位的 `startWeek`／`endWeek`，以及單一欄位的 `location`（視為城市）。

## 設計決策

讀程式碼前先知道這幾件事會省很多時間。

**日期以「日索引」表示。** 第 0 天是 2026-12-28（涵蓋 2027/1/1 那週的週一）。行程在記憶體中是 `{ startDay, endDay }`（含頭尾），存檔時才轉成 ISO 字串。因為第 0 天是週一，`day % 7` 就是星期幾。

**年檢視是顯示上的概略，資料永遠是確切日期。** 時間軸把每週切成兩個半週格（週一–週四、週五–週日）。行程的頭尾各自貼齊最近的半週邊界來畫，但底層日期不變。所以在月檢視把行程改成週三開始，回到年檢視仍會畫在週一或週五。

**拖曳、拉伸、複製各有規則。** 整塊拖曳呼叫 `reorderStays`（像清單排序，會跨越鄰居）；拉兩端呼叫 `pushStays`（順序不變，把鄰居推開）；`Alt` 拖曳呼叫 `insertStay`（把新的一段放進去，擋路的往兩邊推，一邊沒空間就全往另一邊）。三者都是純函式，拖曳過程中每次 pointer move 都從原始資料重新計算，沒有累積狀態，所以拖回原位一定還原。

**行程不可重疊。** 同一天只能在一個地方。所有改動資料的路徑（建立、編輯、拖曳、匯入）都維持這個不變量。

**所有資料變更都經過同一個 `setStays`。** 它負責把舊狀態推進復原堆疊，因此新功能只要走這條路就自動支援復原。

**國家清單不是寫死的。** `flags.ts` 用瀏覽器的 `Intl.DisplayNames` 產生台灣用語的國家名稱（約 260 個），再加上幾個區域選項（歐洲、東南亞、南美洲等）與常見別名。選單挑出來的是名稱字串，存檔時存的就是這個字串，不是代碼。欄位仍接受清單外的文字（為了相容舊資料與特殊情況），但會提示「不在國家清單內」。國旗同樣由名稱對照出來；區域選項除了歐洲以外沒有旗。

**飛行時數是估算。** 依行程順序取相鄰兩地的直線距離，以時速 850 公里加每段 0.5 小時計算；300 公里內視為陸路不計。不含轉機，也不含從家出發與回家。

**PNG 是另外畫的。** `exportPng.ts` 用 canvas 重新繪製，不是截取畫面，所以輸出尺寸固定、不受視窗與縮放影響，但新增的畫面元素不會自動出現在 PNG 裡。

## 已知限制

- **年份寫死 2027。** 常數在 `weeks.ts` 的 `YEAR`；假日資料也只有 2027 年
- **介面只有繁體中文**
- **以桌機為主。** 窄螢幕可用但未最佳化
- **沒有自動化測試**
- **月檢視不能整條拖曳搬移，也不能 `Alt` 拖曳複製**，只能拉兩端或進編輯視窗改日期
- **複製出來的行程不帶機票資料**（機票屬於單一趟行程）
- **一段行程只能記一張機票**
- **國家條、機票標示、地圖不會出現在 PNG 匯出**
- **地圖上的地名是當地文字與英文**，由底圖決定
- **地名查詢依賴 Nominatim**，查不到的地點不會出現在地圖上，該段也不計入飛行估算
- **字體依賴 emfont 線上服務**，離線時退回系統字體
- **澳洲假日只含全國性假日**，各州專屬假日未列
- **復原紀錄不跨重新整理**

## 後續方向

尚未排程，歡迎討論：

- 年份可切換、多年度
- 多語系
- 城市資料庫與搜尋，取代純文字輸入

## 貢獻

歡迎 issue 與 pull request。

- 送出前請確認 `npm run build` 通過
- 改動資料的功能請走 `App.tsx` 的 `setStays`，以維持復原功能
- 調整行程位置的邏輯請放在 `storage.ts` 的純函式裡，並維持「行程不重疊」
- 新增會對外連線的功能，請在本文件的[資料與隱私](#資料與隱私)補上說明
- 介面文字目前為繁體中文
- 功能有變動時，請同步更新 `README.md` 與 `MVP.md`（以及在慣例改變時更新 `CLAUDE.md`）。用 Claude Code 開發時，`.claude/hooks/docs-check.sh` 會在結束前檢查這件事
